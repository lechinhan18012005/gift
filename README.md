# 🌕 Món Quà Trung Thu Gửi Thoa 💕

Trang web quà tặng Trung Thu lãng mạn dành riêng cho Thoa với:
- ✨ Trái tim hạt phát sáng hồng tự động đập nhịp và biến hình mượt mà thành chữ **"Thoa 💕"**.
- 🌕 Không gian đêm rằm Trung Thu huyền ảo với ánh trăng, thỏ ngọc, đom đóm, lồng đèn Trung Thu đung đưa.
- 🖼️ Bức ảnh của Thoa với hiệu ứng bồng bềnh 3D, vệt sáng dạ quang lấp lánh và các vì sao xoay quanh.
- 💌 Bức thiệp Trung Thu với hiệu ứng gõ chữ (typewriter) cùng lời chúc chân thành, ấm áp.
- 🎵 Nhạc nền du dương lãng mạn & tính năng bắn pháo hoa tim tương tác.

## 🚀 Hướng Dẫn Deploy (Đưa Lên Mạng Để Lấy Link Gửi Cho Thoa)

Bạn có 2 cách cực kỳ đơn giản để đưa web lên mạng:

### 🌟 Cách 1: Deploy lên Vercel (Khuyên dùng - Nhanh nhất, chỉ mất 1 phút)

1. Truy cập [vercel.com](https://vercel.com/) và đăng nhập (bằng tài khoản GitHub hoặc Google).
2. Chọn **"Add New..."** -> **"Project"**.
3. Nếu bạn đã đẩy code lên GitHub (theo Cách 2 bên dưới), bạn chỉ cần bấm **"Import"** repository đó và nhấn **"Deploy"**.
4. Hoặc bạn có thể cài Vercel CLI bằng terminal (nếu máy có Node.js):
   ```bash
   npx vercel
   ```
   Làm theo hướng dẫn bấm Enter vài lần là Vercel cấp ngay link web như `https://gift-for-thoa.vercel.app`!

---

### 🌟 Cách 2: Deploy lên GitHub Pages (Miễn phí vĩnh viễn)

Code trong thư mục đã được khởi tạo Git sẵn. Bạn chỉ cần thực hiện 3 bước sau:

#### Bước 1: Tạo Repository trên GitHub
1. Vào [github.com/new](https://github.com/new).
2. Đặt tên repository, ví dụ: `gift-for-thoa`.
3. Để ở chế độ **Public**, **không** tích vào "Add a README file" -> Bấm **Create repository**.

#### Bước 2: Đẩy code lên GitHub
Mở PowerShell tại thư mục này và dán lệnh sau (thay `<username>` bằng tên tài khoản GitHub của bạn):
```bash
git remote add origin https://github.com/<username>/gift-for-thoa.git
git branch -M main
git push -u origin main
```

#### Bước 3: Bật GitHub Pages
1. Tại trang Repository trên GitHub, vào tab **Settings** -> chọn mục **Pages** ở menu bên trái.
2. Tại mục **Branch**, chọn nhánh **`main`** và thư mục **`/(root)`**, sau đó bấm **Save**.
3. Đợi khoảng 1-2 phút, GitHub sẽ hiển thị đường link trang web của bạn:
   👉 `https://<username>.github.io/gift-for-thoa/`

Bây giờ bạn chỉ cần copy link đó và gửi tặng Thoa thôi! 💕
